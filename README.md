- 📌 About Me & Professional Summary  
- 💼 Experience and Projects  
- 🛠️ Skills and Tech Stack  
- 📚 Education & Certifications  
- 🎯 Hobbies Beyond the Resume  
- 📬 Contact Section (email integration)

## 🛠️ Tech Stack

- **Framework**: React (with TypeScript)
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Deployment**: GitHub Pages

## 🚧 Local Development

To run the project locally:

```bash
# Clone the repo
git clone https://github.com/aniket-afk/aniket-afk.github.io.git
cd aniket-afk.github.io

# Install dependencies
npm install

# Start development server
npm run dev
```

## 📦 Deployment

Deployed using `npm run deploy` with GitHub Pages integration.
